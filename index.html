Features

Everything you need for digital forensics

From file upload to PDF report — TraceVault covers the full investigation workflow in one platform.

Email Forensics

Inspect email headers, trace routing paths, detect spoofing, and analyze suspicious links in .eml files.

File Metadata

Extract creation dates, author info, GPS coordinates, software versions, and hidden properties from common file types.

Hash Verification

Calculate SHA-256 hashes to verify evidence integrity and confirm files haven't been tampered with.

Malware Triage

Identify suspicious indicators — embedded macros, obfuscated scripts, unusual PE headers, and known signatures.

AI Summaries

AI-assisted explanations that summarize findings in plain language, identify risks, and suggest next investigative steps.

PDF Reports

Generate professional forensic reports containing evidence details, analysis results, findings, and timeline — ready to share.

Workflow

Four steps from evidence to report

TraceVault is designed around a repeatable, structured investigation workflow.

1
Upload Evidence

Drag and drop or browse to submit a supported evidence file. TraceVault validates type and size before processing.

2
Automatic Analysis

The backend calculates a SHA-256 hash, extracts metadata, and runs applicable forensic checks for the file type.

3
Review Findings

Inspect structured findings, suspicious indicators, and AI-generated explanations tied to observable evidence.

4
Export Report

Download a professional PDF report or revisit saved analysis history at any time.

Analysis Types

Specialized checks for every evidence type

Each analysis type runs a tailored set of forensic checks designed for that evidence category.

Email Forensics
  • Header routing analysis
  • Sender spoofing detection
  • SPF / DKIM / DMARC checks
  • Suspicious link extraction
  • Attachment indicator analysis
  • Timestamp anomaly detection

  • SHA-256 hash calculation

  • Hidden stream detection
  • File signature verification
Malware Triage
  • Macro & script detection
  • Obfuscation indicators
  • PE header analysis
  • String extraction & entropy
  • Known signature matching
  • Behavioral indicators
